## Care Transition and Placement Outcome Analytics

Tools & Technologies:** Python, Jupyter Notebook, Pandas, Power BI, DAX

- Cleaned, preprocessed, and analyzed healthcare care-transition data using Python and Pandas to improve data quality and prepare the dataset for visualization.
- Performed data transformation, validation, and exploratory data analysis to identify patterns in child discharges, placements, care transitions, and backlog levels.
- Designed and developed an interactive Power BI dashboard to monitor key operational performance indicators (KPIs) and analyze trends across different reporting periods.
- Created time-series visualizations to track daily HHS discharges, monthly placement trends, and changes in the number of children in CBP custody compared with HHS care.
- Developed KPI cards and DAX-based measures to evaluate discharge effectiveness, outcome stability, pipeline throughput, transfer efficiency, and backlog accumulation.
- Analyzed care-load and backlog trends to highlight changes in operational workload, discharge activity, and placement performance over time.
- Implemented interactive date filters and dashboard visuals to enable dynamic exploration of the data and support data-driven decision-making.
- Presented key operational insights through a consolidated dashboard to help stakeholders monitor care-transition performance and identify areas requiring further investigation.
